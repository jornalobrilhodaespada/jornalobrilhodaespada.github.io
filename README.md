# O Brilho da Espada — site do leitor

Site do jornal informativo da A.R.L.S. Templários do Vale do Aço Nº 63.

- `index.html`, `assets/`: o leitor (abertura, entrada por e-mail, leitura estilo revista).
- `dados/`: criada e mantida pela área do gestor (Google Apps Script) a cada publicação. Não edite à mão.
